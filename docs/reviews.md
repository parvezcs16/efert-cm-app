# Reviews

## Categories
Initial categories:
- Food
- Environment
- Hygiene
- Server Behavior

## Review Types
- Overall mess review
- Individual order review

Overall mess reviews can be submitted multiple times.

## Privacy
Employee chooses whether a review is anonymous.

Anonymous reviews must not expose employee identity through normal management
review screens.

## Configuration
Support:
- system-defined categories/questions
- optionally manager-defined categories/questions

Keep review configuration versioned enough that historical reviews remain
interpretable when questions change.
